# Area 815 Painting & Restoration

Responsive static website with all local image assets, animations, gallery and SMS estimate request.

## Preview locally
Run `python -m http.server 8000` from this folder and open http://localhost:8000.

## Upload to GitHub
Extract this ZIP and upload the contents of this folder to a new GitHub repository. Keep index.html at the repository root alongside assets/.

## Deploy to Vercel
Import the GitHub repository. Choose Other as the framework preset. Leave Build Command empty and use the repository root as Output Directory (`.` if required). No dependencies or environment variables are required.

## GitHub Pages
Under Settings > Pages, deploy from the main branch and / (root).

## Notes
The estimate form opens the visitor's SMS app; it does not send messages automatically. A copy-message fallback is included for desktops. Images are illustrative inspiration, not claimed as completed client work. The supplied logo was extracted from the screenshot. Google Fonts requires internet access; system font fallbacks are included.
